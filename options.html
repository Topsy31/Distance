Distance From Home

Your API key and home address are encrypted with a passphrase before they're saved. The passphrase itself is never stored — without it, the saved data can't be read back, including by you, so don't forget it.

Saved instantly — applies to your next lookup.

Adds the round-trip distance in parentheses, e.g. "12 mi (24 mi round trip)". Saved instantly.

Used to encrypt/decrypt your data. Required every time you save or unlock.

Needs the Directions API and Geocoding API enabled on the same Google Cloud project.

Getting a Google Maps API key

This stays open while you work through the steps. Google may change wording slightly, but the flow is the same. A billing account is required even though normal personal use stays inside the free monthly allowance.

  1. Open the Google Cloud console. Go to console.cloud.google.com and sign in with a Google account.
  2. Create a project. Click the project dropdown in the top bar → New Project. Name it anything (e.g. "Distance extension") and create it, then make sure that project is selected in the dropdown.
  3. Enable billing. Open the navigation menu (☰) → Billing and link a billing account (you'll add a card). The APIs below won't return results without this, but they have a large free tier for low-volume use.
  4. Enable the two APIs. Go to APIs & Services → Library. Search for Directions API, open it, click Enable. Then do the same for Geocoding API. Both must be on the same project.
  5. Create the key. Go to APIs & Services → Credentials → Create Credentials → API key. Copy the key it shows (starts with AIza).
  6. Restrict the key (recommended). Click the new key to edit it. Under API restrictions choose Restrict key and tick Directions API and Geocoding API. Leave Application restrictions set to None — the extension calls these APIs from a background service worker, so HTTP-referrer and IP restrictions will block it. Save.
  7. Paste it in. Put the key in the Google Maps Platform API key field, add your home address, enter a passphrase, and click Save & encrypt.

If lookups fail later with a billing or authorisation error, it's almost always one of: billing not linked, one of the two APIs not enabled, or the key restricted to the wrong APIs / an application restriction that blocks server-side calls.
